Endpoints

GET /movies
List all movies

Retrieve a paginated list of movies from the dataset. Supports pagination via query parameters.

Query Parameters

Parameter Type Default Description
page integer 1 The page number to retrieve.
limit integer 100 Number of items per page.

Data Schema

Field Type Description
id string Unique identifier for the movie.
title string The official title of the movie.
original_language string ISO 639-1 language code (e.g., 'en', 'es').
popularity number Popularity score based on user engagement.
vote_average number Average rating from 0 to 10.
vote_count number Total number of votes received.
overview string Brief plot summary of the movie.
